# wodaca

Minimal planner for your 60% work-from-office requirement (Capgemini India's
WFO mandate: swipe 60% of the month's effective working days).

Pick a month, planned leaves, and your working state — the office-day target, calendar, and WFH stats update instantly. Click weekdays to toggle office days; type a holiday name and click weekdays to mark custom holidays. Export/import a JSON file to move your setup between devices. Saved to `localStorage`.

## Run

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start Vite dev server
- `npm run build` — production build to `dist/`
- `npm run preview` — serve the production build
- `npm run lint` — ESLint

React + Vite + Tailwind CSS v4. No TypeScript, no backend, no tests.
